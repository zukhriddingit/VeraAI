# Reviewer instructions

Pairing requires a time-boxed review Gateway supplied only through the Chrome Web Store dashboard's
credential field or direct reviewer coordination. No pairing credential is embedded in the ZIP.

1. Install the private item.
2. Open the popup and enter the supplied review pairing value.
3. Click **Prepare Vera Search tab** and observe one visible grouped tab.
4. Click **Stop sharing this tab** and verify there are zero shared tabs.
5. Click **Unpair and revoke browser access** and verify the popup is disconnected.

No marketplace login, contact, application, CAPTCHA bypass, payment, upload, or download is needed.

# Reviewer instructions

Review uses a time-boxed Vera tester account and isolated review Gateway. Tester-account access is
provided only through the Chrome Web Store reviewer-access field or direct reviewer coordination.
No Browser Connector ticket, relay credential, or account credential is embedded in the ZIP.

1. Install the private item and sign in to the supplied Vera tester account.
2. Open **Settings → Browser Connector**, accept the read-only disclosure, and click **Connect this
   browser**.
3. Verify the extension reports connected while zero tabs are shared.
4. Click **Prepare Vera Search tab** and observe one visible grouped tab.
5. Click **Stop sharing this tab** and verify there are zero shared tabs.
6. Revoke browser access in Vera and verify the extension reports disconnected.

No marketplace login, contact, application, CAPTCHA bypass, payment, upload, or download is needed.

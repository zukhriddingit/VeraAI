# Store release checklist

- [ ] Exact v2.2.0 ZIP SHA recorded in private evidence.
- [ ] Privacy and support URLs return 200 over HTTPS.
- [ ] `support@verahousing.app` round-trip succeeds.
- [ ] Visibility is **Private**, with explicit trusted testers only.
- [ ] Deferred publishing is enabled.
- [ ] Permission and privacy declarations match the checked-in source.
- [ ] Reviewer Vera account and isolated Gateway are time-boxed; no browser credential is supplied.
- [ ] No public or unlisted distribution is selected.
- [ ] Private install smoke proves connect, zero shared tabs, prepare, share, unshare, and revoke.
